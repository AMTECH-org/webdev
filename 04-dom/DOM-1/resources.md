## 🎯 Goal

After completing DOM Part 1, students should be able to

- Understand the DOM Tree
- Select HTML elements confidently
- Read HTML content
- Modify HTML content
- Differentiate between innerText, textContent and innerHTML
- Build the foundation for DOM Manipulation
