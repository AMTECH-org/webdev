# 🌐 HTML Level 2 Notes

---

# 📋 Lists

HTML provides two types of lists.

## Ordered List

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

---

## Unordered List

```html
<ul>
    <li>Apple</li>
    <li>Mango</li>
    <li>Orange</li>
</ul>
```

---

# 🔗 Anchor Tag

Anchor tags create hyperlinks.

```html
<a href="https://google.com">Google</a>
```

---

# 🖼 Images

```html
<img src="image.jpg" alt="Sample Image">
```

---

# 📂 Absolute Path

Points to an external location.

Example:

```html
https://example.com/image.jpg
```

---

# 📁 Relative Path

Points to a file inside your project.

```html
images/logo.png
```

---

# 💬 Comments

```html
<!-- This is a comment -->
```

---

# ✨ Formatting Tags

```html
<b>Bold</b>

<i>Italic</i>

<u>Underline</u>
```

---

# 📦 Block Elements

Take the full width.

Examples:

- div
- h1
- p

---

# 📄 Inline Elements

Take only required width.

Examples:

- span
- a
- img

---

# 📦 div

Generic Block Element.

```html
<div>
    Welcome to AMTECH
</div>
```

---

# 🔹 span

Generic Inline Element.

```html
<span>Hello</span>
```

---

# ➖ hr

Horizontal Rule

```html
<hr>
```

---

# 🔻 sub

```html
H<sub>2</sub>O
```

---

# 🔺 sup

```html
x<sup>2</sup>
```
