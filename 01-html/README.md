# 📖 Module Overview

Welcome to the **HTML Module** of the **AMTECH Web Development Program**.

HTML (HyperText Markup Language) is the foundation of every website. In this module, you'll learn how to create structured, semantic, and professional web pages from scratch.

By the end of this module, you'll be able to build complete static websites using only HTML.

---

# 🎯 Learning Outcomes

After completing this module, you will be able to:

- ✅ Understand HTML5 Fundamentals
- ✅ Build Well-Structured Web Pages
- ✅ Create Lists, Links and Images
- ✅ Build Tables
- ✅ Create Forms
- ✅ Use Semantic HTML
- ✅ Build Complete Static Websites
