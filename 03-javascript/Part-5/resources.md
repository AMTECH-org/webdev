After completing Part 5, students should be able to

- Write reusable Functions
- Use Parameters and Arguments effectively
- Return values from Functions
- Understand Scope
- Create Function Expressions
- Build Higher Order Functions
- Work with Methods
- Use the this Keyword correctly
