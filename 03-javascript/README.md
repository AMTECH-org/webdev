# 📖 Module Overview

Welcome to the JavaScript Module.

In this module you will learn how to make websites interactive using modern JavaScript.

This module starts from absolute basics and gradually moves towards DOM Manipulation and real-world projects.

---

# 🎯 Learning Outcomes

After completing this module you will be able to

- Write JavaScript programs
- Understand Variables
- Work with Operators
- Take User Input
- Use Conditional Statements
- Write Loops
- Create Functions
- Work with Arrays
- Work with Objects
- Manipulate the DOM
- Handle Events
- Build Interactive Websites
