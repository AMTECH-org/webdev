Build the following layouts without using Flexbox or Grid.

- Navigation Bar
- Hero Section
- Notification Badge
- Floating WhatsApp Button
- Product Card
- Restaurant Landing Page
- Facebook Login Layout

## 🎯 Goal

After completing Level 3, students should be able to:

- Choose the correct display type
- Position elements accurately
- Use responsive CSS units
- Build layouts using traditional CSS techniques
- Understand when to use Relative, Absolute, and Fixed positioning
