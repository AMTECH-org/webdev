# 🎨 CSS Level 1 Notes

---

# What is CSS?

CSS stands for **Cascading Style Sheets**.

It is used to style HTML webpages by controlling colors, layouts, spacing, fonts, animations, and responsiveness.

---

# Why CSS?

- Makes webpages attractive
- Separates design from structure
- Improves user experience
- Makes websites responsive
- Reduces code duplication

---

# CSS Syntax

```css
selector{
    property: value;
}
```

Example

```css
h1{
    color: blue;
}
```

---

# CSS Components

- Selector
- Property
- Value

Example

```css
p{
    color:red;
}
```

Selector → p

Property → color

Value → red

---

# Ways to Add CSS

## Inline CSS

```html
<h1 style="color:red;">AMTECH</h1>
```

---

## Internal CSS

```html
<style>

h1{
color:red;
}

</style>
```

---

## External CSS

```html
<link rel="stylesheet" href="style.css">
```

# Best Practices

- Prefer External CSS
- Use meaningful class names
- Keep code properly indented
- Group similar styles together
- Avoid inline CSS in large projects

---
