# 🌐 HTML Level 2 – Core HTML Elements

> Welcome to Level 2 of the HTML Module.

In this level, you will move beyond the basics and start building real webpages using HTML elements that are commonly used in every website.

---

# 🎯 Learning Objectives

After completing this level, you will be able to:

- Create Ordered and Unordered Lists
- Create Hyperlinks
- Display Images
- Understand Absolute and Relative Paths
- Use Formatting Tags
- Write HTML Comments
- Differentiate between Block and Inline Elements
- Use div and span effectively
- Display mathematical formulas using sub and sup
- Structure content using hr
