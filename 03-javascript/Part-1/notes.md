# What is JavaScript?

JavaScript is a high-level, interpreted programming language used to make webpages interactive.

---

# Why JavaScript?

- Adds Interactivity
- Manipulates HTML
- Manipulates CSS
- Handles Events
- Makes API Calls

# const

---

# Difference

var

- Function Scoped
- Can Redeclare

let

- Block Scoped
- Cannot Redeclare

const

- Block Scoped
- Cannot Reassign

---
