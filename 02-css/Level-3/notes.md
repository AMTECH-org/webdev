# CSS Level 3 Notes

# Display Property

Controls how an element appears on the webpage.

```css
display:block;
display:inline;
display:inline-block;
display:none;
```

---

# Block Elements

Take the full width available.

Examples

- div
- h1
- p
- section

---

# Inline Elements

Take only the required width.

Examples

- span
- a
- strong
- em

---

# Inline Block

Behaves like inline but accepts width and height.

```css
display:inline-block;
```

---

# Display None

Removes the element completely.

```css
display:none;
```

---

# CSS Units

## Pixels

```css
width:300px;
```

---

## Percentage

```css
width:80%;
```

---

## em

Relative to parent font size.

```css
font-size:2em;
```

---

## rem

Relative to root element.

```css
font-size:2rem;
```

---

# Position Property

Controls the placement of elements.

```css
position:static;
position:relative;
position:absolute;
position:fixed;
```

---

## Static

Default position.

---

## Relative

Moves relative to its original position.

```css
position:relative;
top:20px;
left:20px;
```

---

## Absolute

Moves relative to the nearest positioned parent.

```css
position:absolute;
top:0;
right:0;
```

---

## Fixed

Remains fixed while scrolling.

```css
position:fixed;
bottom:20px;
right:20px;
```

---

# Difference

Static

Default.

Relative

Moves from original position.

Absolute

Moves relative to parent.

Fixed

Always fixed on screen.
