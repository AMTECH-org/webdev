# 🏆 Interview Tip

Don't just memorize answers.

In interviews, explain each concept with:
- Definition
- Purpose
- Syntax
- One practical example

That's how you demonstrate real understanding.

## 🎯 Level 2 Mastery Checklist

Before moving to Level 3, make sure you can confidently:

- ✅ Create Lists
- ✅ Add Hyperlinks
- ✅ Display Images
- ✅ Use Absolute & Relative Paths
- ✅ Apply Formatting Tags
- ✅ Write Comments
- ✅ Differentiate Block & Inline Elements
- ✅ Use `div` and `span`
- ✅ Use `hr`, `sub`, and `sup`

If you can do all of the above without referring to notes, you're ready for **HTML Level 3**.
