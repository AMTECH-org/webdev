After completing Part 3, students should be able to

- Make decisions using Conditional Statements
- Apply Logical Operators correctly

- Accept user input using prompt()
- Display messages using alert()
- Generate random numbers
- Build beginner-level interactive JavaScript programs

## 🚀 Mini Challenge

Build a **Number Guessing Game**.

Requirements

- Generate a random number between 1 and 100.
- Take user input using `prompt()`.
- Compare the guessed number with the generated number.
- Display whether the guess is:
  - Too High
  - Too Low
  - Correct
- Allow the user to play again by refreshing the page.
