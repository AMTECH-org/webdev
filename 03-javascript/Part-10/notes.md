# Terminal

A Terminal is a command-line interface (CLI) that allows users to interact with the operating system using text commands.

Developers use the terminal to

- Navigate folders
- Create files
- Delete files
- Run programs
- Install packages
- Manage Git repositories

---

# Types of Terminals

- Command Prompt (CMD)
- PowerShell
- Git Bash
- Linux Terminal
- VS Code Integrated Terminal

---

# pwd

Displays the current working directory.

```bash
pwd
```

---

# ls

Lists files and folders.

```bash
ls
```

---

# cd

Changes the current directory.

```bash
cd Desktop
```

---

# clear

Clears the terminal screen.

```bash
clear
```

---

# mkdir

Creates a new folder.

```bash
mkdir projects
```

---

# touch

Creates a new file.

```bash
touch index.html
```

---

# rm

Deletes a file.

```bash
rm notes.txt
```

---

# rmdir

Deletes an empty directory.

```bash
rmdir test
```

---

# cp

Copies files or folders.

```bash
cp file1.txt file2.txt
```

---

# mv

Moves or renames files.

```bash
mv old.txt new.txt
```

---

# Absolute Path

Starts from the root directory.

Example

```
C:\Users\Adesh\Documents
```

---

# Relative Path

Starts from the current directory.

Example

```
Documents/Projects
```

---

# Command Flags

Flags modify command behavior.

Examples

```bash
ls -a

ls -l

ls -la
```

---
