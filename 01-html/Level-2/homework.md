# 🏠 HTML Level 1 Homework

> **Module:** HTML  
> **Level:** 1 - HTML Basics

---

# 🎯 Objective

Strengthen your understanding of HTML Basics by practicing independently.

---

# 📌 Task 1

Create a webpage with the following details:

- Your Name
- Your Photo (Placeholder)
- Your College
- Your Branch
- Your Hobbies
- Your Career Goal

Use proper heading tags and paragraphs.

---

# 📌 Task 2

Without using Emmet, write the complete HTML5 Boilerplate from memory.

---

# 📌 Task 3

Create a webpage showing:

```
Welcome to AMTECH

Tech Beyond Limits

Learning Never Stops
```

Use:

- h1
- h2
- h3
- Paragraphs

---

# 📌 Task 4

Practice all heading tags.

Create one webpage containing:

```
Heading 1
Heading 2
Heading 3
Heading 4
Heading 5
Heading 6
```

---

# 📌 Task 5

Write five paragraphs on any one topic:

- Artificial Intelligence
- Cricket
- Technology
- Space
- Your Favorite Movie

---

# 📌 Task 6

Answer the following in your own words:

1. What is HTML?
2. What is HTML5?
3. What is HyperText?
4. What is Markup Language?
5. What is an HTML Element?

---

# 🌟 Bonus Task

Research:

- Who invented HTML?
- When was HTML first introduced?

Write the answers in a separate file.
